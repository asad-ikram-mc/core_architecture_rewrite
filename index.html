NEW Architecture — Dashboards

V2 monitoring lives in the qa.* schema in Aurora PostgreSQL — query directly. S3 dashboard planned for Phase 7.

QA Schema — Queryable Postgres Tables (no CSV hunting)
qa.pipeline_runs
Every run — status, step reached, row counts, elapsed time
qa.filtered_posts
All 21 filter rules in one table — replaces 5 CSVs
qa.duplicate_candidates
T9 dedup — pending/approved/rejected/resolved lifecycle
qa.duplicate_checks
Legacy dedup query results per run
qa.data_quality_issues
Schema drift — missing files, unexpected column changes
qa.collab_priority_decisions
T3 collab priority rule audit per run
V2 S3 monitoring dashboard is planned for Phase 7. For now query qa.* tables directly via RDS Query Editor or check the V1 Quality Dashboard comparison tab.
